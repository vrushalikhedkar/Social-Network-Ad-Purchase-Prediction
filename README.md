# Social Network Ads Purchase Prediction

## 📌 Project Overview
Predict whether a user will purchase a product based on:
- Age
- Estimated Salary

## 📊 Dataset
- Dataset: Social Network Ads
- Total Records: 400
- Features: Age, Estimated Salary
- Target: Purchased
- 0 = Not Purchased
- 1 = Purchased

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔄 Machine Learning Workflow
1. Data Loading
2. Data Understanding
3. Data Visualization
4. Train-Test Split
5. Model Training
6. Prediction
7. Model Evaluation
8. Model Comparison

## 🤖 Models Used

| Model | Parameters | Accuracy |
|---|---|---:|
| Logistic Regression | Default | 91.25% |
| KNN | n_neighbors=10 | 83.75% |
| Decision Tree | random_state=10 | 91.25% |
| Random Forest | random_state=20 | 93.75% |

## 🏆 Best Model
Random Forest Classifier

**Accuracy: 93.75%**
